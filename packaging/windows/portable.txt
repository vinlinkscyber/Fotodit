Fotodit portable mode

While this file sits next to fotodit.exe, Fotodit keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the FotoditData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Fotodit with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\Fotodit for settings
and %LOCALAPPDATA%\Fotodit\Recovery for crash-recovery autosaves. If FotoditData can't be
written (for example on a read-only drive), Fotodit says so and uses those folders instead.
